# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) where applicable.

## [Unreleased]

### Added

- Customizable global shortcuts: Settings > **Shortcuts** (validated, failed registrations keep the previous shortcuts); tray menu, tooltip and Info page show the current combinations
- Snapshot PNG files: Settings > **Snapshot** (`snapshot_save_png`, `snapshot_output_path`); `Ctrl+S` in annotate mode saves the annotated screen as PNG
- GIF frame rate setting: 5 / 10 / 15 / 20 FPS (`gif_fps`)
- GIF frame resize grips: 8 square handles inside the frame (corners and edge centers); hidden while recording so they never appear in the GIF
- Global hotkey `Ctrl+Alt+Shift+R` — open GIF frame → start recording → stop
- Tray balloon notifications: snapshot copied, GIF saved, recording errors; tray tooltip shows recording state
- Tray menu: shortcut hints, bold default item (Settings), **Click Effects** on/off toggle
- GIF capture toolbar: elapsed `● REC mm:ss.t` while recording, tooltips on buttons/combos
- Annotate mode: start hint, `F1` shortcut cheat sheet, `Ctrl+C` copies the annotated screen
- Single instance: launching again opens Settings in the running instance instead of a second tray icon
- Unit tests (`cargo test`) for config, recorder timing, capture sizing, settings helpers, Win32 utils; screen-recording smoke test via `cargo test -- --ignored`
- Settings: **Browse...** for the GIF folder (offers to create a missing folder on save), Info page with version, all shortcuts, config file location + **Open Folder**

- `docs/` folder structure (`development/`, `operations/migration/`, `planning/`, `reference/`)
- Root `CHANGELOG.md` and per-doc YAML frontmatter
- Folder READMEs under `docs/`
- Reference docs: `config-storage.md`, `deployment-facts.md`
- Pen cursor in screen annotation (draw) mode — tinted from `assets/draw-pen.png`
- Striped GIF capture frame (idle: white/black, recording: red/black)
- Global hotkeys: `Ctrl+Alt+Shift+C` (snapshot), `Ctrl+Alt+Shift+A` (annotate)
- `capture_frame` in `config.json` — remembers GIF frame size/position with monitor fallback

### Changed

- GIF toolbar scales with monitor DPI (bar, buttons, font, Per-Monitor `WM_DPICHANGED`); minimum frame size scales too. Narrow frames hide the preset / ratio / position combos instead of covering the size text
- New app/tray icon: monochrome line art traced 1:1 from the `assets/icon001-1.svg` sketch (frame, divider lines, cursor, click circle), generated by `tools/icon/gen_icon.py`; 16–48 px drawn on the pixel grid (1–2 px strokes), transparent background, 10-size ICO
- Tray icon follows the taskbar theme — black lines on light, white lines on dark (`SystemUsesLightTheme`), updated live on `WM_SETTINGCHANGE("ImmersiveColorSet")`; exe uses the black icon (resource ID 1), white is ID 2
- Tray and title-bar small icons load via `LoadIconMetric(LIM_SMALL)` — native small sizes instead of a downscaled 32 px
- Settings window scales with monitor DPI (Per-Monitor V2, `WM_DPICHANGED`) and uses Segoe UI
- Settings checkboxes carry their own labels (click the text to toggle); dependent options are disabled when their parent option is off
- Hotkey registration error lists exactly which shortcuts failed
- GIF recorder reuses GDI objects for the whole recording and encodes on a separate thread (bounded queue of 8 frames; frame delays use real elapsed time, so playback speed stays correct when the encoder lags)
- When "Start with Windows" is on, the Run entry is refreshed with the current exe path at launch (moved exe keeps auto-starting)

- Migrated `doc/` → `docs/`; updated Cursor rule links
- English UI strings (tray, settings, capture UI, error messages); code comments remain Korean
- GIF capture frame clamps to virtual screen when dragged off-screen (no black capture padding)
- Cursor architecture link points to `docs/reference/architecture.md`
- App/tray icon source switched to `assets/icon-entry-3.png` (single multi-size ICO; no theme-split tray icons)
- Embed ComCtl32 v6 application manifest (`assets/app.manifest`) and call `InitCommonControlsEx` for themed Win32 controls
- Settings: `ask_gif_save_path` — when on, prompt for GIF filename/folder after recording ends (Cancel discards)
- Docs synced to current code (architecture, roadmap, backlog, config-storage, project-standards)

### Fixed

- Typing non-ASCII text in a settings color field crashed the app
- Cancelling the Save As dialog deleted the recording without asking; a dialog failure was treated as a cancel and also deleted it
- Exiting while recording with "Ask where to save" on left the GIF in `%TEMP%` — now moved to the GIF folder and reported
- Exit waited only 3 s for the encoder (large GIFs could be truncated) while the mouse hook slowed system input — hook is removed first, wait is up to 30 s, a timeout is reported
- Windows sign-out / shutdown now finishes an active recording (`WM_ENDSESSION`)
- Esc or the annotate shortcut discarded annotations without asking — now confirms unless already copied or saved
- Settings OK overwrote a GIF frame position or tray Click Effects toggle changed while the window was open
- Unreadable (e.g. non-UTF-8) `config.json` was overwritten without a backup
- GIF frame: dragging or a preset past the screen edge cropped the frame so the recording area differed from what was shown — it now moves and keeps its size
- GIF frame: preset and ratio could be changed during a recording (frame moved, recorded area did not) — locked while recording
- Record shortcut during the Save As dialog started a second recording and mixed up the output files
- Recorded cursor was offset by its hotspot (I-beam, resize cursors)
- GIF toolbar's discard button was disabled while recording, despite its tooltip — it now works, with a confirmation
- GIF output folder changes applied only after reopening the frame
- GIF toolbar could end up off-screen on a full-height frame — frame height now leaves room for the toolbar (`screen height − 32 px`)
- Snapshot: releasing a mouse button held when the overlay opened copied a wrong area; pressing the shortcut during a selection broke the overlay state
- Snapshot / annotate copy failed if another app briefly held the clipboard — now retries
- Annotate start and click-effect window failures were silent — now reported
- Folder Browse dialog ran without the COM initialization it requires
- Losing mouse capture mid-drag left annotate / GIF frame drags stuck
- Large annotate blur froze the UI — blur cost no longer depends on the radius
- Stopping a GIF recording from the tray left the capture toolbar stuck (no Save As / open folder; temp GIF left behind)
- GIF recording failures (e.g. invalid output folder) were silent — now shown as an error
- Exiting while recording could truncate the GIF — shutdown now waits for the encoder to finish
- A corrupt `config.json` was silently overwritten with defaults — now backed up to `config.json.bak`; saves are atomic (`.tmp` + rename)
- Save As copy failure no longer deletes the recording (kept at the temp path)
- Settings General page: last row overlapped the Reset button
- Settings window: Tab / Enter (OK) / Esc (Cancel) keyboard navigation

- Draw annotation slowdown as stroke count grows — bake finalized strokes into `committed` buffer ([incident-draw-render-performance.md](docs/reference/incident-draw-render-performance.md))
