# 문제점
화면 위쪽으로 드래그가 불가하다.
따라서 화면 맨위에 영역을 둘때 틀 이 두꺼워서 그만큼 손해보면서 녹화된다.

프리셋콤보선택했을때 이상하다.
예를들어 640x480을 선택했는데 바에는 632x472가 표시되고 실제로 녹화된 gif도632x472로 녹화 되었다.

# 아이디어/해결법
- 현재 바 에 존재하는 버튼과 기능들을, 녹화영역 정중앙에 두면 어떨까
- 틀을 없애고 녹화영역은 투명, 그 외 영역은 불투명으로 

tab이나 alt로 콤보나 버튼조작되는건 불가능하게하라.



만약 흰색인 영역에서 틀을 가져다두면 틀색깔이 흰색이라 녹화영역이 불분명함으로. 틀의 색깔을 불투명하고 색반전색깔로해서 어느곳에가도 틀이 분명히 보이도록 하는거 어때.
