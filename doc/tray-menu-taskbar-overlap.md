# 트레이 컨텍스트 메뉴와 작업표시줄 겹침 문제

## 증상

Windows 11에서 트레이 아이콘의 컨텍스트 메뉴를 열 때 메뉴가 순간적으로 보인 뒤 작업표시줄 영역과 겹쳐 보이는 문제가 있었다. 사용자가 관찰한 현상은 작업표시줄 높이가 평소와 다르게 보이고, 마우스를 한 번 누르면 다시 정상처럼 보이는 형태였다.

## 원인

트레이 아이콘은 하단 작업표시줄 안에 있으므로, 메뉴를 여는 시점의 마우스 좌표도 작업표시줄 내부에 있다. 이 상태에서 `TrackPopupMenu`에 `TPM_BOTTOMALIGN`을 사용하면 메뉴의 아래쪽 끝이 해당 마우스 좌표에 맞춰진다.

그 결과 메뉴 창(`#32768`)의 아래쪽이 작업표시줄 위가 아니라 작업표시줄 내부까지 내려갔다. 디버그 계측에서 확인한 대표 값은 다음과 같다.

- 작업표시줄: `top=1140`, `bottom=1200`
- 문제 시 메뉴 창: `top=1076`, `bottom=1171`

즉 메뉴가 작업표시줄 영역 안으로 31px 들어가 있었고, 이 겹침 때문에 작업표시줄이 낮아지거나 메뉴가 뒤로 가려지는 것처럼 보였다.

## 수정

하단 작업표시줄 안에서 메뉴를 열 때는 `TrackPopupMenu`의 기준 y 좌표를 마우스 좌표 그대로 쓰지 않고, 작업표시줄 위쪽 경계 바로 위로 보정한다.

- 마우스 좌표가 작업표시줄 내부일 때: `menu_y = taskbar.top - 1`
- 기존 `TPM_BOTTOMALIGN`은 유지
- `SetForegroundWindow(hwnd)` 호출도 유지

수정 후 디버그 계측에서는 메뉴 창의 `bottom=1139`, 작업표시줄의 `top=1140`으로 확인되어, 메뉴가 작업표시줄 바로 위에서 끝났다.
